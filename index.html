    Clavier d'ordinateur : rangée A S D F… (ou Q S D F en AZERTY) = touches blanches, rangée du dessus = touches noires. En mode Magique, n'importe quelle touche joue la note suivante. Flèches ← → : changer d'octave.

    100 % gratuit, sans publicité, sans compte. Tes morceaux restent sur ton appareil.

    Écrire un morceau

    Une note = nom + octave : C4 ou Do4, F#5 ou Fa#5, Bb3 ou Sib3. Accord : C4+E4+G4. Durée : :2 (elle reste la même pour les notes suivantes). Silence : -. Astuce : en mode Libre, le bouton ● enregistre ce que tu joues.
